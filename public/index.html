Learn

How Cohort works, from first click to first company.

1

Pick a handle

No signup, no password — choose a handle and you're in. It identifies you in workspaces, chats and upvotes.

2

Learn by contributing to open source

Open the Open Source tab: every repo listed has beginner-friendly “good first issues”. Pick one that matches your interests, read its contributing guide, then: fork the repo on GitHub → clone your fork → create a branch → make the fix → open a pull request. One merged PR teaches you more than ten tutorials — and it's a public track record.

3

Join or start a project

Browse Projects to find teams looking for your skills, or start your own with a one-breath pitch and “looking for” tags. Link your GitHub repo so contributors can find the code.

4

Build together in the workspace

Every project has a live shared workspace: an editor everyone can type in and a team chat. Draft specs, sketch APIs, plan launches — everything syncs in real time.

5

Bring your own AI

Open ⚙ AI Settings, pick a provider and paste an API key — Gemini, Groq and OpenRouter all have free tiers (no credit card). Then type @ai in any team chat: the whole team sees the question and the answer. Your key stays in your browser.

6

Grow it into a business

Ship something small, show it to ten real users, and iterate on what they say. Upvotes move you up the Leaderboard — visibility brings collaborators. The News tab keeps you current with what founders and hackers are talking about.

Start a project

Pitch it in one breath. You can refine everything later in the workspace.
